Shelf L 形展開

點球後展開成 L 形：球在轉角，橫的一臂是「分類 + 搜尋」，從球往旁邊抽出來；直的一臂是內容清單，從球往上長。兩塊是分開的卡片，中間留 8 px 間隙，各自有 Windows 11 的圓角與陰影。

球在三種位置

L 形跟著球所在的角落翻轉：球在右邊，分類往左抽；球在左邊，往右抽。球靠近螢幕頂端時，內容改往下長。

點 🔍 之後

橫的一臂整條變成搜尋框 + ✕；內容清單即時過濾，搜尋所有類型。

尺寸規格

部件尺寸位置（以球在右下為例）
球56 × 56使用者拖到哪就在哪
分類列（橫）300 × 56，與球同高右緣在球左邊 8 px，和球垂直置中
內容清單（直）寬 300，高度跟著筆數（最多工作區 70%）右緣對齊球的右緣，底部在球上方 8 px
間隙8 px三塊之間都是 8 px

分類列比清單往外多突出 64 px，所以從遠處看得出是 L 形；清單不再包含分類列，同樣高度可以多放一筆。
