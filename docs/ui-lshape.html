Shelf L 形展開

點球後展開成 L 形：分類列（月牙膠囊）在球旁邊，內容清單（柔和卡片）在上方。兩塊左緣對齊、同一個出發點；靠球那端都挖出同一個圓的凹口，球就嵌在兩塊共同的凹槽裡。

球在三種位置

點 🔍 之後

幾何規格

以球在右下為例（單位：邏輯像素）。凹口圓 = 以球心為圓心、半徑 44（球半徑 28 + 間隙 16）。兩塊和球之間的距離處處相同。

部件規格
球56 × 56，使用者拖到哪就在哪
凹口圓圓心 = 球心，半徑 44；分類列右端、清單右下角都沿這個圓挖掉
分類列高 56（與球同高、垂直置中）；左端半圓頭；右端凹口，尖角離球心水平 33.9
內容清單寬 350、高度跟著筆數；22 px 圓角；底部在球上方 8 px（＝和分類列之間的間隙）；右緣離球心 25.3，右下角沿凹口圓挖掉成尖角
左緣分類列與清單左緣對齊；分類列寬 = 清單寬 − 59.2（兩個凹口的水平差）
尖角四個尖角都修圓（約 6° 弧長），不會刺
