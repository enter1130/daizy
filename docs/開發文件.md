# Shelf（暫定名稱）開發文件

> 輕量級桌面暫存架：拖入檔案、自動收集剪貼簿文字與圖片，懸浮於所有視窗之上，隨時拖出或貼上使用。
> 目標是取代 Win+V，但常駐記憶體壓在 50 MB 以下、操作零延遲。

版本：v0.2 草稿　｜　日期：2026-10-28　｜　平台：Windows 10 / 11（x64）

---

## 1. 目標與非目標

### 1.1 目標

| 編號 | 目標 | 驗收標準 |
|---|---|---|
| G1 | 常駐記憶體低 | 閒置時私人工作集 ≤ 15 MB、工作集 ≤ 50 MB；收集 200 筆後私人工作集 ≤ 40 MB、工作集 ≤ 80 MB（量法見 1.3） |
| G2 | 操作零延遲 | 熱鍵叫出視窗 < 100 ms，拖放回應即時 |
| G3 | 三種內容都能收 | 檔案（含多選）、純文字、圖片 |
| G4 | 雙向流動 | 拖進來、拖出去、單擊複製 |
| G5 | 懸浮於任何視窗之上 | 含全螢幕瀏覽器、Office、檔案總管 |
| G6 | 單一 exe | 開發時依賴已安裝的 .NET 10 Desktop Runtime（exe < 1 MB）；對外提供含 Runtime 的安裝檔（見第 2 節、9.1） |

### 1.2 非目標（第一版不做）

- 跨裝置雲端同步
- 富文本（RTF / HTML）格式保留，第一版一律降成純文字
- 剪貼簿內容加密
- 多語系（第一版只做繁體中文）
- 自動分類、OCR、AI 功能

### 1.3 記憶體量法與基準

- **私人工作集**：工作管理員「詳細資料」頁預設的「記憶體」欄，只算這個程式獨佔的記憶體。對外比較一律用這個。
- **工作集**：含共用的系統 DLL 與 .NET Runtime 映射，同一台機器上多個程式會重複計算，只作參考。
- 量法：啟動後靜置 8 秒，讀 `Win32_PerfFormattedData_PerfProc_Process` 的 `WorkingSetPrivate` / `WorkingSet`。

2026-10-28 實測（Windows 11，M0 空面板，.NET 10）：

| 對象 | 私人工作集 | 工作集 |
|---|---|---|
| Win+V 背景服務（`cbdhsvc`） | 5.2 MB | 42.3 MB |
| Win+V 介面（`TextInputHost.exe`，與表情符號、觸控鍵盤、輸入法共用） | 114 MB | 232 MB |
| Shelf：單檔、壓縮、R2R | 74.2 MB | 116.2 MB |
| Shelf：單檔、不壓縮、R2R | 11.9 MB | 54.2 MB |
| Shelf：單檔、不壓縮、無 R2R（含 Runtime，110 MB） | 8.9 MB | 45.8 MB |
| **Shelf：單檔、不含 Runtime、不壓縮、無 R2R（採用，172 KB）** | **8.5 MB** | **44.4 MB** |

網路上說「Win+V 只用 2 MB」指的是背景服務的私人工作集，不含按 Win+V 跳出的介面。

## 2. 技術選型

| 項目 | 選擇 | 理由 |
|---|---|---|
| 語言 / 框架 | C# 14 / .NET 10（LTS，支援至 2028-11；.NET 8 將於 2026-11-10 停止支援）/ WinForms | 拖放、剪貼簿、置頂、熱鍵、系統匣皆有現成封裝；記憶體約為 WPF 的 2/3、Electron 的 1/4 |
| 發佈方式 | `PublishSingleFile`，`SelfContained=false`，**不壓縮、不 ReadyToRun** | 單一 exe 172 KB，需已安裝 .NET 10 Desktop Runtime（個人自用，可接受）。若日後要給別人用、需免安裝，改 `SelfContained=true`（exe 約 110 MB，記憶體相同）。**不可開壓縮**：私人工作集會從 9 MB 暴增到 74 MB（實測見 1.3）。WinForms 不支援 Trim 與 Native AOT |
| 儲存 | 檔案系統 + 一個 `index.json` | 不引入 SQLite，200 筆以內 JSON 足夠，零相依 |
| JSON | `System.Text.Json` + Source Generator | 不用反射，啟動較快 |
| 圖片 | `System.Drawing`（GDI+） | WinForms 內建，不加套件 |
| 原生 API | P/Invoke（`user32.dll`） | 剪貼簿監聽、熱鍵、視窗樣式 |

**明確不用**：Electron、Tauri、WPF、Avalonia、任何 NuGet UI 套件。

## 4. 系統架構

```
┌──────────────────────────────────────────────────────┐
│ ShelfForm（主視窗，WinForms）                           │
│   ├─ 標題列：搜尋、釘住視窗、設定、關閉                   │
│   ├─ 篩選列：全部 / 檔案 / 文字 / 圖片 / 釘選             │
│   ├─ ItemListView（自繪 Control，不可取得焦點）          │
│   └─ 狀態列：筆數、磁碟用量、清空                         │
├──────────────────────────────────────────────────────┤
│ 服務層（無 UI 相依）                                     │
│   ├─ ClipboardMonitor   WM_CLIPBOARDUPDATE 監聽          │
│   ├─ ItemFactory        IDataObject → ShelfItem（剪貼簿與拖入共用）│
│   ├─ SourceApp          視窗 → 來源程式名稱                 │
│   ├─ DragOutBuilder     拖出組裝（ShelfItem → DataObject）│
│   ├─ HotkeyService      RegisterHotKey                    │
│   └─ TrayService        NotifyIcon                       │
├──────────────────────────────────────────────────────┤
│ 儲存層                                                   │
│   ├─ ShelfStore         記憶體清單 + index.json 讀寫       │
│   ├─ BlobStore          大內容落地（PNG / TXT）            │
│   └─ ThumbnailCache     96 px 縮圖，LRU 上限 100 張        │
├──────────────────────────────────────────────────────┤
│ Native（P/Invoke 集中在一個靜態類別）                      │
│   AddClipboardFormatListener / RegisterHotKey /          │
│   GetClipboardOwner / SHGetFileInfo / SetWindowPos       │
└──────────────────────────────────────────────────────┘
```

**設計原則**

1. UI 層只碰 `ShelfItem` 的中繼資料，永遠不直接讀大內容。
2. 服務層不引用 `System.Windows.Forms`（`DataObject` 除外），方便單元測試。
3. 所有 P/Invoke 集中在 `Native.cs`，方便之後開 `AllowUnsafeBlocks` 或換成 CsWin32。

## 5. 資料模型與儲存

### 5.1 ShelfItem

```csharp
enum ItemKind { File, Text, Image }

sealed record ShelfItem
{
    public required Guid Id { get; init; }
    public required ItemKind Kind { get; init; }
    public required DateTime CreatedAt { get; init; }
    public bool Pinned { get; set; }

    /// 清單上顯示的一行文字：檔名 / 文字前 80 字 / "圖片 1920×1080"
    public required string Title { get; init; }

    /// File：原始路徑（多檔用 \n 分隔）
    /// Text：若 ≤ 4 KB 直接放這裡，否則為 null 並改存 BlobPath
    /// Image：null
    public string? Inline { get; init; }

    /// 落地檔案的相對路徑（store/{Id}.png 或 .txt），Inline 有值時為 null
    public string? BlobPath { get; init; }

    public long SizeBytes { get; init; }
    public string ContentHash { get; init; }   // SHA-256 前 16 bytes，用於去重
    public string? SourceApp { get; init; }     // 來源程式名稱（選填，從剪貼簿擁有者取，取不到用前景視窗）
    public bool IsFolder { get; init; }         // File 且為單一資料夾；建立時判斷一次，繪製時不碰磁碟
}
```

### 5.2 磁碟配置

```
%LOCALAPPDATA%\Shelf\
├─ settings.json        使用者設定
├─ index.json           List<ShelfItem>，每次異動後延遲 500 ms 寫入（debounce）
├─ store\
│   ├─ {guid}.png       圖片原檔（PNG，無損）
│   └─ {guid}.txt       長文字（UTF-8）
└─ thumbs\
    └─ {guid}.jpg       96 px 縮圖（JPEG 品質 75），可隨時刪除重建
```

### 5.3 記憶體策略（本專案的核心）

| 內容 | 記憶體裡放什麼 | 磁碟裡放什麼 |
|---|---|---|
| 檔案 | 路徑字串 + 系統圖示（共用快取） | 不複製檔案 |
| 短文字（≤ 4 KB） | 字串本身 | 不落地 |
| 長文字 | 前 80 字標題 | 全文 .txt |
| 圖片 | 96 px 縮圖（≈ 30 KB） | PNG 原檔 |

規則：

- 剪貼簿收到 `Bitmap` 後：存 PNG → 產縮圖 → **立刻 `Dispose()` 原圖**，整個流程不超過 1 秒並在背景執行緒做。
- 縮圖用 LRU 快取，上限 100 張，超過就釋放 `Image` 物件，需要時從 `thumbs\` 重讀。
- 讀圖：開串流 → `Image.FromStream` → **複製成 `new Bitmap(decoded)`** → 關串流。GDI+ 要求串流在 Image 存活期間保持開啟，直接關串流會在之後繪製時炸掉。**不用 `Image.FromFile`**（會鎖檔）。
- 清單是自繪 Control，只畫可見列；不用 `ListBox` / `ListView`，因為它們點擊時會 `SetFocus`，啟用視窗、繞過 `WS_EX_NOACTIVATE`（6.1）。
- 系統圖示用 `SHGetFileInfo` 取 `hIcon` 後轉 `Icon`，依副檔名快取，相同副檔名共用一份。
- 啟動時只讀 `index.json`，不碰 `store\`。

預估：200 筆混合內容，工作集約 35 至 45 MB。

## 6. 關鍵實作細節

### 6.1 永遠置頂、不佔工作列、不搶焦點

```csharp
ShowInTaskbar = false;
FormBorderStyle = FormBorderStyle.None;
// 不設 TopMost 屬性：它內部的 SetWindowPos 不帶 SWP_NOACTIVATE，會讓 ShowWithoutActivation 失效

protected override CreateParams CreateParams
{
    get
    {
        var cp = base.CreateParams;
        cp.ExStyle |= 0x00000008;   // WS_EX_TOPMOST：改由這裡置頂
        cp.ExStyle |= 0x00000080;   // WS_EX_TOOLWINDOW：Alt+Tab 不出現
        cp.ExStyle |= 0x08000000;   // WS_EX_NOACTIVATE：點擊時不搶走前景視窗焦點
        return cp;
    }
}
protected override bool ShowWithoutActivation => true;
```

`WS_EX_NOACTIVATE` 很重要：使用者在 Word 打字時點了架子上的項目複製，焦點仍留在 Word，直接按 Ctrl+V 就能貼上。

**副作用：NOACTIVATE 視窗收不到鍵盤輸入**，搜尋框、↑ ↓ Enter、Esc、Del、P 都會失效。焦點策略採「預設不搶、需要打字才借」：

| 情境 | 焦點行為 |
|---|---|
| 滑鼠操作（單擊、拖出、右鍵） | 不啟用，焦點留在原視窗 |
| 點分頁列的 🔍 / 搜尋框，或按熱鍵叫出 | 暫時移除 `WS_EX_NOACTIVATE`（`SetWindowLong(GWL_EXSTYLE)`）並 `Activate()`，進入「鍵盤模式」，分頁列變成搜尋框並取得焦點。點 ✕ 回到分頁時結束鍵盤模式、焦點還給原程式。熱鍵是使用者明確要操作，所以直接給焦點（同 Win+V）；系統匣點開則不搶焦點 |
| 鍵盤模式下按 Enter 複製 / Esc / 點回原視窗 | 恢復 `WS_EX_NOACTIVATE` 並隱藏，系統把焦點交還原視窗 |

鍵盤模式期間 `Deactivate` 事件觸發時自動退出。

### 6.2 剪貼簿監聽

```csharp
// 註冊
Native.AddClipboardFormatListener(Handle);

// 攔訊息
protected override void WndProc(ref Message m)
{
    const int WM_CLIPBOARDUPDATE = 0x031D;
    if (m.Msg == WM_CLIPBOARDUPDATE) OnClipboardChanged();
    base.WndProc(ref m);
}
```

`OnClipboardChanged` 流程：

1. `Clipboard.GetDataObject()` 可能因其他程式鎖住而丟 `ExternalException`，用 **重試 5 次、間隔 100 ms** 包住（`await`，不卡 UI）。原本 3 次 × 50 ms，實測連續複製 4K 截圖 50 張漏收 2 張；放寬後全收。
2. 含 `Shelf.Self` 格式（自己寫入的）就 return。不用 bool 旗標：旗標在連續操作或別的程式搶先寫入時會錯位。
3. 含 `ExcludeClipboardContentFromMonitorProcessing`，或 `CanIncludeInClipboardHistory` 值為 0 就 return（F6b）。
4. 判斷順序（`ItemFactory.Capture`）：
   - **剪貼簿**：檔案 → 文字 → 圖片。檔案一定最先，否則會被當成路徑文字；文字先於圖片，因為 Excel / Word 複製時會順便附一張截圖，使用者要的是文字。
   - **拖入**：檔案 → 圖片 → 文字。瀏覽器拖圖會順便附網址文字，使用者要的是圖。
   - 圖片優先取 `PNG` 格式（保留透明、免重新編碼），沒有才取 `Bitmap`。
5. 算 `ContentHash`，與最新一筆相同就略過（F5）。
6. 建 `ShelfItem`，大內容交給 `BlobStore` 在 `Task.Run` 內落地。
7. `Invoke` 回 UI 執行緒插入清單頂端。

程式自己寫入剪貼簿或拖出時，`DragOutBuilder.Build` 都會在 `DataObject` 上多放一個 `Shelf.Self` 格式（內容 1 byte）；拖回自己身上也據此忽略。

### 6.3 拖入（Drop Target）

```csharp
AllowDrop = true;
DragEnter += (s, e) => e.Effect =
    e.Data.GetDataPresent(DataFormats.FileDrop) ||
    e.Data.GetDataPresent(DataFormats.Bitmap)   ||
    e.Data.GetDataPresent(DataFormats.UnicodeText)
        ? DragDropEffects.Copy : DragDropEffects.None;
DragDrop += (s, e) => _dropHandler.Handle(e.Data);
```

瀏覽器拖圖片時常常只給 `text/html` 或 URL 而不給 `Bitmap`，第一版策略：有 `Bitmap` 就收圖，否則收成文字（URL）。

### 6.4 拖出（Drag Source）

```csharp
void Item_MouseDown(object? s, MouseEventArgs e)
{
    if (e.Button != MouseButtons.Left) return;
    _dragStart = e.Location;
}
void Item_MouseMove(object? s, MouseEventArgs e)
{
    if (e.Button != MouseButtons.Left) return;
    if (Math.Abs(e.X - _dragStart.X) < SystemInformation.DragSize.Width &&
        Math.Abs(e.Y - _dragStart.Y) < SystemInformation.DragSize.Height) return;

    var data = _dragOut.Build(item);     // 見下
    DoDragDrop(data, DragDropEffects.Copy);
}
```

`DragOutBuilder.Build`：

| Kind | DataObject 內容 |
|---|---|
| File | `SetFileDropList(StringCollection)`；路徑不存在時提示並不啟動拖曳 |
| Text | `SetText(text, TextDataFormat.UnicodeText)`，長文字從 .txt 讀 |
| Image | `SetImage(bitmap)`，**同時** `SetFileDropList` 指向 store 裡的 PNG，這樣拖到檔案總管變檔案、拖到 Word 變圖片 |

### 6.5 ~~雙擊貼上~~（已移除）

2026-10-28 實測後移除：送 Ctrl+V 到原前景視窗不可靠，且單擊複製後自己按 Ctrl+V 已足夠。單擊複製用 `Clipboard.SetDataObject(data, copy: true, ...)`，`copy: true` 會立刻把所有格式寫進剪貼簿，之後圖片的 Bitmap 就能釋放。

### 6.7 浮動球（2026-10-28 取代原本的靠邊色帶）

使用者要的是類似聊天球的設計。平常只有一顆球（`BubbleForm`），面板（`ShelfForm`）收起時是隱藏的。

**球**
- 48 px 圓球（視窗 72 px，留邊給陰影與放大），置頂、不搶焦點。
- 可拖到任何位置，放哪就停哪（不吸附邊緣），限制在游標所在螢幕的工作區內。開始拖動時面板先收起（同聊天球）。位置存在 `settings.json`（`BubbleX` / `BubbleY`，實體像素）；那個螢幕不在了就回到主螢幕右下。
- 用分層視窗 + `UpdateLayeredWindow` 逐像素畫：圓邊平滑，圓外透明處滑鼠會點穿。分層視窗不走 `OnPaint`，外觀變化都要呼叫 `Render()`；`OnShown` 要再畫一次，否則建立 handle 時 WinForms 依 DPI 調整位置，第一次畫的位置會錯。
- ~~新項目徽章~~：做了之後使用者覺得難看，移除。
- 拖檔案到球上：球在 120 ms 內漸變放大到 60 px、變綠、圖示改成向下箭頭；放開直接收進來，不展開面板。
- 暫停收集時球變灰（同系統匣圖示）。

**面板**
- 點一下球（沒有拖動）才展開，開在球的上方，一側和球對齊、往螢幕中間展開：球在右半邊就面板右緣對齊球右緣、往左開，在左半邊就左緣對齊、往右開，像聊天視窗從角落的聊天球長出來。球太靠近螢幕頂端、上面放不下時才改開在下方。寬 300 px，高度最多工作區 70%，空間不夠就縮（最小 320 px）。
- 收起：點面板和球以外的地方、再點一次球、Esc、✕、熱鍵再按一次。
- 「點外面」用低階滑鼠 hook（`WH_MOUSE_LL`，`OutsideClickWatcher`）偵測：面板帶 `WS_EX_NOACTIVATE`，沒被啟用就收不到 `Deactivate`。hook 只在面板展開時掛上。點系統匣圖示時 hook 先收起面板、圖示的 click 又會打開，所以收起後 300 ms 內忽略系統匣的切換。
- 不收起的情況：「釘住視窗」開啟、右鍵選單或對話框開著、拖出進行中。
- 啟動時面板不顯示：覆寫 `SetVisibleCore` 擋下 `Application.Run` 的第一次顯示，只建立 handle（熱鍵、剪貼簿監聽要用）。要先 `base.SetVisibleCore(false)` 再 `CreateHandle()`，反過來的話 handle 帶 `WS_VISIBLE`，一建立就出現。
- 面板展開 / 收起有動畫（7.10）：面板視窗常駐 `WS_EX_LAYERED`，用 `SetLayeredWindowAttributes` 調整整個視窗透明度，子控制項照常繪製。動畫進行中 `Visible` 仍是 true，判斷「面板開著沒」一律看 `_showing`。
- 第二次啟動 exe 會叫出面板：找同名行程裡標題為 "Shelf" 的視窗直接 `PostMessage`。不用 `HWND_BROADCAST`，實測送不到。
- 用 `SetWindowPos` 加 `SWP_NOACTIVATE` 移動，不要改 `Location`（會閃）。Windows 11 用 `DWMWA_WINDOW_CORNER_PREFERENCE` 加圓角。

### 6.8 DPI

`Program.cs` 呼叫 `Application.SetHighDpiMode(HighDpiMode.PerMonitorV2)`；`app.manifest` **不要**再設 DPI（兩邊都設會出 WFAC010 警告）。所有尺寸用 `LogicalToDeviceUnits()` 轉換，不要寫死像素。

### 7.10 動畫

WinForms 沒有內建動畫，一律用 15 ms 計時器逐格計算，緩動函數 ease-out cubic（先快後慢），共用 `Anim` 類別。

| 過渡 | 時間 | 效果 |
|---|---|---|
| 面板展開 / 收起 | 160 ms | 淡入淡出，並從球的方向滑動 16 px；淡出完才 `Hide` |
| 新項目出現 | 180 ms | 列高從 0 長到 56 px 並淡入，下面的項目被往下推 |
| 刪除項目（含清空、超過上限淘汰） | 180 ms | 列淡出並縮回 0，下面的項目往上補 |
| 懸停底色 | 120 ms | panel → panel2 漸變 |
| 篩選膠囊切換、懸停 | 120 ms | 底色與文字顏色漸變 |
| 單擊複製的閃光 | 450 ms | accent-soft 淡出 |
| 拖檔案到球上 | 120 ms | 球放大、藍轉綠 |
| 滾輪捲動 | 約 150 ms | 每格走剩下距離的 30%，平滑停下 |
| 捲軸出現 / 變寬 / 淡出 | 150 ms | 見 7.8 捲軸 |

- 搜尋打字、切換篩選造成的清單變化**不做**動畫：一次大量項目同時出現消失，畫面反而亂。
- 清單每一列有自己的高度進度，位置要逐列累加，不能用 index × 列高；懸停、選取以項目 `Id` 追蹤，不用 index（動畫中 index 會變）。
- 淡入淡出用「蓋一層半透明底色」做：`TextRenderer` 不支援透明度。

HTML 版視覺示意另見 [ui-mockup.html](ui-mockup.html)。

### 9.1 安裝檔（2026-10-28）

- 工具：Inno Setup 6（免費，不用改程式）。腳本 `installer/Shelf.iss`，用 `installer/build.ps1 -Version x.y.z` 產生 `artifacts/ShelfSetup-x.y.z.exe`。
- 安裝檔**包含 .NET Runtime**（`dotnet publish -p:SelfContained=true`）：約 33 MB，裝好約 115 MB，任何 Windows 10 / 11 x64 都能直接裝。記憶體與不含 Runtime 的版本相同（實測私人工作集 8.8 MB）。
- 裝到 `%LOCALAPPDATA%\Programs\Shelf`，`PrivilegesRequired=lowest` 不需要系統管理員權限。
- 開始功能表捷徑；「設定 → 應用程式」可解除安裝；`AppId` 固定，新版安裝檔直接覆蓋升級，`CloseApplications=force` 先關掉執行中的 Shelf。
- 安裝選項「開機時自動啟動」寫的登錄值和程式內設定相同，所以設定頁的開關改為讀登錄檔（`AutoStart.IsEnabled()`），不看 settings.json。
- 解除安裝保留 `%LOCALAPPDATA%\Shelf` 使用者資料。
- 介面語言用官方原始碼庫的社群繁中翻譯 `ChineseTraditional.isl`（Inno Setup 沒有內建）。
- 程式圖示 `src/Shelf/Shelf.ico`：「口袋」標誌，品牌紅圓角方塊，16 到 256 px 共 8 個尺寸，由 `Shelf.exe --export-icon` 產生（見 7.2）。

## 11. 已知風險與對策

| 風險 | 對策 |
|---|---|
| 其他程式（Excel、遠端桌面）長時間鎖剪貼簿 | 讀取加重試，失敗就跳過此次，不要阻塞 UI 執行緒 |
| 收到密碼管理員複製的密碼 | 提供「暫停收集」；忽略帶 `ExcludeClipboardContentFromMonitorProcessing` 或 `CanIncludeInClipboardHistory` = 0 的內容（主流密碼管理員都會標，Win+V 也遵守同一套規則） |
| 提權（UAC）視窗拒絕拖放 | 無法繞過，README 說明；可改用單擊複製後自己貼上 |
| 瀏覽器拖圖只給 URL | 第一版收成文字，之後可選配「下載為圖片」 |
| `Clipboard.GetImage()` 對某些 DIB 格式回傳變色或 null | 優先取 `PNG` 格式，其次 `DeviceIndependentBitmap`，自己解 BITMAPINFOHEADER |
| 換電腦或重灌後缺 .NET 10 Desktop Runtime | 啟動時 Windows 會自動跳出下載連結；或改發佈含 Runtime 的版本（第 2 節） |
| NOACTIVATE 導致無法打字 | 鍵盤模式：需要時才暫時取得焦點，結束時歸還（6.1） |
| 多個實例同時執行 | `Mutex` 單實例，第二次啟動只把既有視窗叫出來 |
