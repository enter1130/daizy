1. 主畫面：展開狀態（淺色）

面板寬 300 px、高為工作區的 70%，貼齊右緣。滑鼠停在第二筆上，顯示懸停動作（複製、釘選、刪除）。第一筆為釘選項目，左側有金色標記並固定置頂。

5. 互動流程摘要

動作結果視覺回饋
滑鼠靠近右緣色帶面板展開150 ms 滑出動畫
Win+Alt+V切換顯示 / 隱藏；顯示時記住目前前景視窗同上，不搶焦點
拖檔案到面板DragEnter 時面板展開並顯示藍框；放下後新增至清單頂端新項目淡入，120 ms
Ctrl+C（任何程式）自動收進清單頂端；與上一筆相同則略過系統匣圖示閃一下（可關）
單擊項目複製到剪貼簿項目短暫亮一下，狀態列顯示「已複製」1.5 秒
按住拖曳項目DoDragDrop，拖到其他程式半透明拖曳影像
懸停項目右側顯示 複製 / 釘選 / 刪除列底色變 panel2
點「清空」確認對話框，確認後刪除所有未釘選項目
Esc隱藏面板
點搜尋框 / 熱鍵叫出後打字進入鍵盤模式：暫時取得焦點，Esc 或貼上後歸還原視窗搜尋框出現藍色外框
搜尋框輸入即時過濾，中文也可清單立即更新，不閃
