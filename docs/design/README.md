# 設計草稿

開發過程中用來比較方案的 HTML 草稿，用瀏覽器直接開。保留作為設計紀錄，**與目前的介面不一定相同**；現況以 [開發文件](../開發文件.md) 為準。

| 檔案 | 內容 |
|---|---|
| `ui-ios.html` | 目前採用的版面：分離式分類列（網址加 `#static` 關掉動畫） |
| `ui-lshape.html` | 舊版：融合抽屜 |
| `ui-tabbar.html` | 舊版：底部分頁列 |
| `ui-simplify.html` | 介面簡化的比較 |
| `ui-mockup.html` | 最早的視覺示意 |
| `logo-options.html` | 標誌方案比較（採用方案 1「口袋」） |
| `icon-options.html` | 圖示方案比較 |
